# SMARTPARK AI

Smart Parking Availability Prediction and Intelligent Parking Management System Using Machine Learning.

## Project Summary
SMARTPARK AI is a machine learning web platform that predicts parking occupancy and manages parking space availability across multiple locations.

The platform combines a React and TypeScript frontend, a Python FastAPI backend, Scikit-learn regression models, and an SQLite database for persistent storage.

## Key Features
- **Module 1: Main Dashboard**: Displays total capacity, occupied spots, vacant bays, occupancy percentage, demand level, and 24-hour availability trends.
- **Module 2: Availability Prediction**: Allows users to input garage location, date, time, weather, and event flags to predict expected occupancy and demand using Scikit-learn regressors.
- **Module 3: Interactive Parking Layout**: Grid layout showing bays color-coded by status (Green = Available, Red = Occupied, Yellow = Reserved). Includes slot inspection and simulation controls.
- **Module 4: Multiple Parking Locations**: Tracks 5 parking facilities (Downtown Metro Hub, Tech Park Plaza, Grand Central Mall, Airport Terminal 2, and University Campus North).
- **Module 5: Analytics**: Visual charts for hourly curves, day-of-week trends, ground-truth vs. predicted comparisons, and cross-location benchmarks.
- **Module 6: Reservation Simulation**: Allows users to select an available bay, input driver information, simulate a reservation, view history, and cancel reservations.
- **Module 7: ML Performance & Evaluation**: Real holdout test set metrics (MAE, RMSE, R-squared) across Linear Regression, Decision Tree, and Random Forest.
- **Module 8: About Project**: Detailed documentation on the problem statement, objectives, feature engineering pipeline, algorithms, and system architecture.

## Tech Stack
- Frontend: React 19, TypeScript, Vite, Tailwind CSS, Recharts, Lucide Icons
- Backend: Python 3.12, FastAPI, Uvicorn, SQLAlchemy, Pydantic v2
- Machine Learning: Scikit-learn, Pandas, NumPy, Joblib, SciPy
- Database: SQLite

## Setup Instructions

### Backend Setup
1. Open a terminal in the project root:
   ```bash
   pip install -r requirements.txt
   ```
2. Train models and generate dataset (if not already trained):
   ```bash
   python backend/train_models.py
   ```
3. Run backend tests:
   ```bash
   python backend/test_backend.py
   ```
4. Start FastAPI server:
   ```bash
   uvicorn backend.app.main:app --host 127.0.0.1 --port 8000 --reload
   ```
   API docs are available at `http://localhost:8000/docs`.

### Frontend Setup
1. In another terminal, navigate to the frontend directory:
   ```bash
   cd frontend
   npm install
   npm run dev
   ```
2. Open your browser at `http://localhost:5173`.

## Telemetry Simulation Notice
Parking slot status transitions and telemetry movements in this project are generated by an internal simulation engine for demonstration and validation purposes. It does not use camera-based hardware detection.
